01
ثغرة XSS Cross-Site Scripting
HIGH RISK
ثغرة XSS تسمح بحقن أكواد JavaScript خبيثة في صفحات الويب. عند تنفيذ الكود، يمكن للمهاجم سرقة الكوكيز، جلسات المستخدم، أو إعادة توجيه الضحية لمواقع ضارة.
// Payload:
<script>alert('XSS')</script>
💡 جرب إدخال: <script>alert('XSS')</script> ثم اضغط بحث
02
ثغرة SQL Injection SQL Injection (SQLi)
CRITICAL
ثغرة حقن SQL تسمح للمهاجم بالتلاعب باستعلامات قاعدة البيانات. يمكن من خلالها تجاوز المصادقة، سرقة بيانات حساسة، تعديل أو حذف السجلات، وحتى التحكم الكامل بالخادم.
// Password Payload:
' OR '1'='1
💡 استخدم اسم المستخدم: admin وكلمة المرور: ' OR '1'='1
03
ثغرة LFI Local File Inclusion
HIGH RISK
ثغرة تضمين الملفات المحلية تسمح للمهاجم بقراءة ملفات حساسة من خادم الويب مثل ملفات التكوين، كلمات المرور، أو حتى تنفيذ أكواد برمجية عن بعد عبر تضمين ملفات ضارة.
// Path Traversal Payload:
../../etc/passwd
💡 جرب: readme.txt أو ../../etc/passwd
04
ثغرة SSRF Server-Side Request Forgery
CRITICAL
ثغرة SSRF تسمح للمهاجم بجعل الخادم يُصدر طلبات HTTP إلى مواقع داخلية أو خارجية نيابة عنه. يمكن استغلالها للوصول إلى خدمات داخلية، سرقة بيانات من Metadata APIs، أو تجاوز جدران الحماية.
// Internal Network Payload:
http://127.0.0.1:8080/admin
http://169.254.169.254/latest/meta-data/
💡 جرب: http://127.0.0.1:8080 أو https://example.com
